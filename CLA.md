## 6. How to sign

Add the following statement, unchanged, to the description of your first pull request
(the pull request template contains it as a checkbox), and sign off your commits with
`git commit -s`:

> it for this and all my future contributions to this project.

Contributions made on behalf of an organisation need the statement from someone
authorised to bind that organisation.
